#Ports

Ports identify services running on a device

Port 80: HTTP for unencrypted web pages.
Port 443: HTTPS for secure, encrypted web pages.
Port 22: SSH (Secure Shell) for safe remote logins.
Port 23: TELNET for unencrypted remote logins. File and Mail Transfer Ports
Port 20 / 21: FTP (File Transfer Protocol) for moving files.
Port 25: SMTP for sending email.
Port 110: POP3 for receiving email.
Port 143: IMAP for managing email on a server. Core Network Services
Port 53: DNS (Domain Name System) for matching names to IP addresses.
Port 67 / 68: DHCP for assigning IP addresses to devices. 
Port 123: NTP for syncing clocks across a network
